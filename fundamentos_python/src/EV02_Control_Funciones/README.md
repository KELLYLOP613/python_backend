# EV02 – Control y Funciones

Esta evidencia corresponde al desarrollo de la **Guía 02 – Control y Funciones**, perteneciente al curso **Python Avanzado** del programa **Tecnólogo en Análisis y Desarrollo de Software (ADSO)** del **Servicio Nacional de Aprendizaje (SENA)**.

## Objetivo

Desarrollar programas en Python aplicando estructuras de control y funciones para resolver diferentes problemas mediante el uso de condicionales, ciclos y modularización del código.

# Contenido

| Sección | Temas desarrollados |
|----------|---------------------|
| **Sección 1 - Condicionales** | Estructuras `if`, `if...else`, `if...elif...else`, condicionales anidados y operador ternario. |
| **Sección 2 - Estructuras iterativas** | Ciclos `for` y `while`, uso de `break`, `continue`, `pass` y cláusula `else` en los bucles. |
| **Sección 3 - Funciones** | Definición de funciones, parámetros, argumentos, valores de retorno, alcance de variables y docstrings. |

# Competencias desarrolladas

Durante el desarrollo de esta evidencia se fortalecieron las siguientes habilidades:

- Implementación de estructuras condicionales para la toma de decisiones.
- Desarrollo de algoritmos utilizando ciclos de repetición.
- Aplicación de las instrucciones `break`, `continue` y `pass` para controlar el flujo de ejecución.
- Creación de funciones reutilizables para mejorar la organización del código.
- Uso de parámetros y valores de retorno para modularizar programas.
- Documentación de funciones mediante **docstrings**, siguiendo buenas prácticas de programación.

# Cómo ejecutar los programas

1. Tener instalado **Python 3.13** o una versión superior.
2. Abrir una terminal ubicada en la raíz del proyecto.
3. Ejecutar el archivo deseado.

Ejemplo:

```bash
python fundamentos_python/src/EV02_Control_Funciones/seccion3_funciones/01_definicion_basica.py
```

Cada archivo puede ejecutarse de forma independiente.
